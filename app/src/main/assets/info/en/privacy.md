# Privacy Policy

Last updated: 2026

## General Provisions

**Intuition** respects the right of users to privacy.

The application is designed to collect only the data that is necessary for its operation and improvement.

## Personal Data

In this document, personal data is any information relating to an identified natural person or such a natural person who can be directly or indirectly identified.

## Service Data

In this document, service data is technical information about the application, its installation, software and hardware environment, as well as the characteristics of the runtime environment, which is used to ensure the performance, compatibility, diagnostics and statistical analysis of the application.

## Statistical data

In this document, statistical data is information about the use of the application, the progress and results of the user's game tasks, which are used to conduct statistical research and improve the application.

## Installation ID

The application uses the Installation ID to distinguish data received from different installations of the application. The Installation ID does not contain information about a natural person. The application does not collect data that, when combined with the Installation ID, allows you to directly or indirectly identify the user.

The Installation ID is randomly generated on the user's device when the application is first launched.

The Installation ID is used exclusively to distinguish data between different installations and is not associated with the user's identity.

## Anonymization

The application does not collect information that directly identifies a natural person, including name, email address, phone number or other similar data.

The profile names that the user sets when working with the application are used exclusively locally on the device and are not transmitted together with statistical or service data.

The transmitted data does not contain information that allows you to directly identify a person.

## Data transfer and use

To improve the application, diagnose its operation and conduct statistical research, the Installation ID, service and statistical data are automatically transmitted.

Service and statistical data are used exclusively as part of the aggregate of data obtained from many installations of the application, to conduct statistical research and improve the application.

For automatic analysis of errors and crashes, the application uses the Google Firebase Crashlytics service, which receives service data necessary for diagnosing the operation of the application.

The application does not use the received data to track users between applications, websites or services of other companies.

The application does not transmit personal data.

## Data storage

Local application data is stored on the device for the period specified by the user in the application settings. After the expiration of the set period, outdated local data may be automatically deleted.

The transferred service and statistical data is stored by the author for the period he considers necessary for conducting statistical research, analyzing the application's operation and improving it.

## Data deletion

You do not need to create a user account to use the application.

After deleting the application or clearing its data, the connection between the new application installation and previously transferred statistical information is lost.

The next time you start the application, the application creates a new installation with a new Installation ID. In this regard, restoring previous local data and establishing its belonging to a new application installation is impossible.

## Policy changes

The privacy policy may be updated in future versions of the application.

The current version is always available within the application.
