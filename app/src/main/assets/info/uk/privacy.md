# Політика конфіденційності

Останнє оновлення: 2026


## Загальні положення

**Intuition** поважає право користувачів на приватність.

Застосунок розроблено таким чином, щоб збирати лише ті дані, які необхідні для його роботи та вдосконалення.


## Персональні дані

У цьому документі персональні дані — це будь-яка інформація, що стосується ідентифікованої або такої, яку можна прямо чи опосередковано ідентифікувати, фізичної особи.


## Службові дані

У цьому документі службові дані — це технічна інформація про застосунок, його встановлення, програмне та апаратне середовище, а також характеристики середовища виконання, яка використовується для забезпечення працездатності, сумісності, діагностики та статистичного аналізу роботи застосунку.


## Статистичні дані

У цьому документі статистичні дані — це відомості про використання застосунку, перебіг і результати виконання користувачем ігрових завдань, що використовуються для проведення статистичних досліджень та вдосконалення застосунку.


## Installation ID

Застосунок використовує Installation ID для розрізнення даних, отриманих від різних встановлень застосунку. Installation ID не містить відомостей про фізичну особу. Застосунок не збирає даних, які у поєднанні з Installation ID дають змогу прямо чи опосередковано ідентифікувати користувача.

Installation ID випадково генерується на пристрої користувача під час першого запуску застосунку.

Installation ID використовується виключно для розмежування даних різних встановлень та не пов'язується з особою користувача.


## Анонімізація

Застосунок не збирає відомостей, які безпосередньо ідентифікують фізичну особу, зокрема імені, адреси електронної пошти, номера телефону чи інших аналогічних даних.

Назви профілів, які користувач задає під час роботи із застосунком, використовуються виключно локально на пристрої та не передаються разом зі статистичними або службовими даними.

Передані дані не містять інформації, яка дає змогу безпосередньо ідентифікувати особу.


## Передача та використання даних

Для покращення застосунку, діагностики його роботи та проведення статистичних досліджень автоматично передаються Installation ID, службові та статистичні дані.

Службові та статистичні дані використовуються виключно у складі сукупності даних, отриманих від багатьох встановлень застосунку, для проведення статистичних досліджень та вдосконалення застосунку.

Для автоматичного аналізу помилок і збоїв застосунок використовує сервіс Google Firebase Crashlytics, який отримує службові дані, необхідні для діагностики роботи застосунку.

Застосунок не використовує отримані дані для відстеження користувачів між застосунками, вебсайтами чи сервісами інших компаній.

Застосунок не передає персональні дані.


## Зберігання даних

Локальні дані застосунку зберігаються на пристрої протягом строку, визначеного користувачем у налаштуваннях застосунку. Після закінчення встановленого строку застарілі локальні дані можуть автоматично видалятися.

Передані службові та статистичні дані зберігаються автором протягом строку, який він вважає необхідним для проведення статистичних досліджень, аналізу роботи застосунку та його вдосконалення.



## Видалення даних

Для використання застосунку не потрібно створювати обліковий запис користувача.

Після видалення застосунку або очищення його даних втрачається зв'язок між новим встановленням застосунку та раніше переданою статистичною інформацією.

Під час наступного запуску застосунок створює нове встановлення з новим Installation ID. У зв'язку з цим відновлення попередніх локальних даних та встановлення їх належності новому встановленню застосунку є неможливим.


## Зміни політики

Політика конфіденційності може оновлюватися у майбутніх версіях застосунку.

Актуальна редакція завжди доступна всередині застосунку.
