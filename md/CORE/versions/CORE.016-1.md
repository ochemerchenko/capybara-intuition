# Runtime Truth Principle

The project intentionally treats:

```text
runtime behavior
```

as:

```text
canonical product truth
```

Meaning:

* gameplay semantics must be real,
* analytics must observe actual runtime behavior,
* telemetry must remain observational,
* persistence must reconstruct deterministic facts,
* runtime labels must match runtime execution.

This principle became critical after reducer-era runtime collapse where BEFORE gameplay semantics were declared but not actually implemented.

The current runtime intentionally removed:

* reducer-driven continuation,
* synthesized gameplay semantics,
* hidden runtime reconstruction,
* pseudo-orchestration runtime graphs.

The surviving runtime model is:

```text
event
→ router
→ semantic runtime handler
→ runtime execution context
→ next runtime event
```

instead of:

```text
generic reducer orchestration
```
