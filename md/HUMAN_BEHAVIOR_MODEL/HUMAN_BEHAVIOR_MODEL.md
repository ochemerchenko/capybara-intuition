# HUMAN_BEHAVIOR_MODEL.md

# Human Behavior Model

## Purpose

The purpose of this model is to generate a realistic historical dataset describing
how a person interacts with the training application over time.

The model does **not** attempt to reproduce real human psychology precisely.
Instead, it aims to generate statistically plausible data suitable for testing,
analytics development and UI validation.

The generator produces a complete history consisting of:

- daily emotional, physical and intellectual states;
- daily motivation;
- game sessions;
- rounds inside every session;
- round results;
- decision times.

The generated data should produce realistic analytical charts while remaining
completely deterministic with respect to the selected generator parameters.

---

# Generation Pipeline

The dataset is generated in several independent stages.

```
Timeline
    ↓
Biorhythms
    ↓
State influence factors
    ↓
External motivation events
    ↓
Daily motivation
    ↓
Sessions per day
    ↓
Session level distribution
    ↓
Rounds per session
    ↓
Decision time
    ↓
Round results
```

Each stage receives only the information generated by previous stages.

---

# 1. Timeline

The generator creates one `TimeLineDay` object for every day of the requested
historical period.

Each object accumulates all generated information related to this calendar day.

---

# 2. Biorhythms

Three independent cyclic processes are generated.

## Emotional rhythm

Represents the current emotional balance.

Typical period:

```
28 days
```

---

## Physical rhythm

Represents current physical endurance.

Typical period:

```
23 days
```

---

## Intellectual rhythm

Represents current intellectual activity.

Typical period:

```
33 days
```

---

Each rhythm is normalized to the interval

```
0.0 .. 1.0
```

where larger values do **not** necessarily mean "better".

The interpretation depends on the specific subsystem.

---

# 3. State Influence Factors

Raw biorhythm values are transformed into influence probabilities.

The transformation is performed using Gaussian distributions.

For every subsystem an optimal state exists.

Example:

```
Emotion
best state = 0.5

Physical
best state = 1.0

Intellect
best state = 1.0
```

The further the current state is from its optimum,
the larger the probability that this subsystem will influence behaviour.

Important:

The resulting value is **not** an influence magnitude.

It is only the probability that an influence event will occur.

---

# 4. External Motivation Events

The external world is simulated independently of the person's state.

Positive events are randomly distributed across the timeline.

Examples:

- encouragement;
- successful training;
- praise;
- unexpected inspiration.

Every generated event adds

```
motivationBoost
```

for the corresponding day.

These events are independent of emotional or physical conditions.

---

# 5. Daily Motivation

Motivation evolves from day to day.

Base motivation gradually decays.

External positive events temporarily increase it.

Emotional and physical conditions may additionally modify motivation.

The current implementation assumes:

```
motivation
=
base
- emotional influence
- physical influence
+ external boosts
- natural decay
```

The resulting motivation is always normalized to

```
0.0 .. 1.0
```

---

# 6. Session Count

Daily motivation determines the number of game sessions.

Higher motivation leads to more sessions.

Training intensity acts as a multiplier.

The resulting number is rounded to an integer.

---

# 7. Session Level Distribution

The total number of daily sessions is distributed between game levels.

Lower levels receive significantly more sessions.

Higher levels receive fewer sessions because users naturally prefer tasks with
higher probability of success.

Current distribution uses inverse proportional weighting.

```
weight(level)

=

1 / level
```

The weights are normalized so that the total number of generated sessions
matches the required daily session count.

---

# 8. Rounds Per Session

Every session consists of multiple rounds.

The number of rounds depends on accumulated fatigue.

Fatigue grows after every completed round.

Physical condition slows fatigue accumulation.

After fatigue reaches a threshold,
the probability of finishing the session gradually increases.

This produces realistic distributions of session lengths.

---

# 9. Decision Time

Every day has its own characteristic decision time.

Decision time is affected by:

- emotional state;
- intellectual state.

Emotional instability increases hesitation.

High intellectual influence also increases decision time because the player
starts overthinking a trivial task.

Each round receives a decision time generated around the daily baseline.

---

# 10. Round Result

Each round is generated independently.

Winning probability depends primarily on

```
competence
```

Self-confidence influences the probability of changing the initial decision.

The final result is stored as

```
WIN
```

or

```
LOSE
```

---

# Model Philosophy

The model intentionally separates three independent concepts.

## Human properties

Examples:

- competence;
- self-confidence.

These describe **who the generated person is**.

---

## Environment

Examples:

- external motivation events.

These describe **what happens around the person**.

---

## Behaviour

Examples:

- motivation;
- session count;
- decision time;
- fatigue.

These emerge naturally from interactions between
human properties and environmental events.

---

# Design Principles

- Every subsystem has a single responsibility.
- Independent processes remain statistically independent.
- Every generated value belongs to the interval expected by the analytical model.
- The generator favours understandable business rules over mathematical complexity.
- Parameters are calibrated to produce realistic analytical charts rather than exact psychological simulations.

---

# Future Extensions

The current architecture allows adding new behavioural factors without changing
existing generation stages.

Possible future additions include:

- weekdays vs weekends;
- vacations;
- illness;
- long-term burnout;
- rewards;
- adaptive competence growth;
- learning curves;
- age-dependent behaviour.
